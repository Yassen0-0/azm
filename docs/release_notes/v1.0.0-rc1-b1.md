## عزم 1.0.0-rc1 — نسخة تجريبية 1

أول نسخة تجريبية (مفيش نسخة قبلها). فيها:
- تسجيل التمرين: سِتات بالكيباد، "السابق"، تايمر راحة بإشعار، ملخص بالأرقام القياسية.
- روتينات وبرامج جاهزة، وأول تشغيل يسألك عن الوحدة (kg/lb).
- مكتبة 1,291 تمرين بأسماء مصري عربي + إنجليزي، والبحث بيفهم ظهر/ضهر، ذراع/دراع، ثقيل/تقيل.
- السجل والإحصائيات، وتقدر تعدّل تمرين قديم.
- الإعدادات: الوحدة، وقت الراحة، اللغة، المظهر، نسخة احتياطية (تصدير/استرجاع)، التراخيص.

ملحوظة: صور وفيديوهات التمارين مش موجودة لسه (أيقونة بدلها).

## Azm 1.0.0-rc1 — tester build 1

First tester build (no earlier release). Includes:
- Workout logging: sets with the keypad, "previous", rest timer with a notification, summary with PRs.
- Routines and ready programs; first run asks for your unit (kg/lb).
- Library of 1,291 exercises with Egyptian-Arabic + English names; search matches ظهر/ضهر, ذراع/دراع, ثقيل/تقيل.
- History and stats, including editing a past workout.
- Settings: unit, rest time, language, theme, backup export/import, licences.

Note: exercise images/videos aren't included yet (an icon is shown instead).
